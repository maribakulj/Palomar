# Vendored XML schemas

Kept at the path of their URL, so the LIDO validator
(`palomar.plugins.lido-schema`) resolves every import from here and never
fetches one. Downloaded on 2026-10-28, unmodified.

- `schemas.opengis.net/gml/3.1.1/`: GML 3.1.1, which both LIDO schemas
  import. Copyright Open Geospatial Consortium, under the terms of
  <http://www.opengeospatial.org/legal/> (its SMIL 2.0 part: copyright W3C,
  <http://www.w3.org/Consortium/Legal/>).

  (`1999/xlink.xsd`), which GML imports. Copyright W3C, under the W3C
